===========================
Carrier Restrict Connection
===========================

This module allows to restrict the connection with carriers according to the operation type.


Installation
============

To install this module, you need to:

#. Just install.


Configuration
=============

To configure this module, you need to:

#. Go to those operation types and check the Set Carrier Connection checkbox for those that accept connections.


Usage
=====

To use this module, you need to:

#. No instructions required


ROADMAP
=======

#. The journal whose invoices are transfered cannot be configured.
